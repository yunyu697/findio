# Findio 界面设计规范

适用代码：`src/Findio.UI`（WinUI 3）。
令牌来源：[DesignTokens.xaml](../src/Findio.UI/DesignTokens.xaml)（尺寸）与 [Themes.xaml](../src/Findio.UI/Themes.xaml)（颜色）。
数值基线：`1.1.3` 已交付、截图确认过的界面；本规范不发明新数值，整理的是现状里已经在用的阶梯。

## 1. 目的与约束

1. 后续改功能时，新增界面只能引用令牌，不再写裸数字/裸颜色；
2. 存量偏差由 [Test-LpDesignTokens.ps1](../tools/Test-LpDesignTokens.ps1) 扫描并冻结在 [design-token-baseline.json](../tools/design-token-baseline.json)，只允许减少、不允许新增；
3. 例外必须有理由，理由写在基线条目的 `reason` 字段，并在本文 §6 归类说明。

## 2. 令牌总览

### 2.1 间距阶梯（`LpSpace*`，单位 DIP）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `LpSpace0` | 0 | 清零 |
| `LpSpaceXxs` | 2 | 图标与文字的最小间隙、紧凑徽标内边距 |
| `LpSpaceXs` | 4 | 快捷键徽标内边距、紧凑列表行内边距 |
| `LpSpaceS` | 6 | 小间距（标签与值、按钮组内） |
| `LpSpaceM` | 8 | 默认组件间隙；QS 栏与对话框间隙（已确认） |
| `LpSpaceL` | 10 | 行内左右留白、次级分组间距 |
| `LpSpaceXl` | 12 | 卡片内边距、区块内分隔 |
| `LpSpace2xl` | 16 | 分组之间 |
| `LpSpace3xl` | 20 | 大区块之间 |
| `LpSpace4xl` | 24 | 页面级分隔 |

语义间距（不进通用阶梯，只用于固定版面）：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `LpSpacePage` | 18 | 设置页内容区上下留白 |
| `LpSpaceSection` | 22 | 设置页区块之间的纵向间距 |
| `LpSpaceDialog` | 26 | 对话框/页面左右安全边距 |

### 2.6 颜色与状态色

颜色只允许用 [Themes.xaml](../src/Findio.UI/Themes.xaml) 的画刷（浅色/深色各一套）：

| 类别 | 令牌 |
| --- | --- |
| 表面 | `SurfaceBrush` / `Surface2Brush` / `Surface3Brush` |
| 文字 | `TextBrush` / `Text2Brush` / `Text3Brush` |
| 边框 | `Border1Brush` / `Border2Brush` |
| 强调 | `AccentBrush` / `AccentHoverBrush` / `AccentPressedBrush` / `AccentInkBrush` / `AccentSoftBrush` |
| 状态 | `OkBrush` `#2E9E6B`、`WarnBrush` `#C77A18`、`DangerBrush` `#D9503F` |

状态色只表达语义（成功/警告/错误），不用于装饰；状态点直径与文字颜色成对出现，不单独换色。

### 2.7 标题栏与内容区

- 标题栏固定 `LpSizeCaption`（40 DIP），标题文字 `LpTextBase`（12.5），窗口按钮 `46 x 40`（宽度属结构尺寸，见 §6）；
- 内容区不侵入标题栏：页面根容器从标题栏下方开始，顶部留白 `LpSpacePage`（18）；
- 页面左右安全边距 `LpSpaceDialog`（26），区块之间 `LpSpaceSection`（22）；
- 对话框内边距 `LpSpaceDialog`（26），对话框与 QS 栏的间隙 `LpSpaceM`（8，已确认）。

## 3. 使用方式

XAML：

```xml
<Button Height="{StaticResource LpSizeButton}"
        Padding="14,0"
        CornerRadius="{StaticResource LpRadiusButton}"
        FontSize="{StaticResource LpTextButton}" />
```

注意：`Thickness`/`CornerRadius` 只能整体引用，**不能**写成 `Padding="{StaticResource LpSpaceL},0"`；复合内边距继续写字面量，直到出现稳定的语义组合令牌。

C#（代码后置设置尺寸）：

```csharp
var lpHeight = (double)Application.Current.Resources["LpSizeTool"];
```

颜色一律 `ThemeResource` 画刷，不在 C# 里构造颜色；需要透明度时基于画刷颜色派生（如 `Color.FromArgb(alpha, themeColor.R, ...)`），不算硬编码。

## 4. 允许内联的值

以下情况不要求令牌，也不计入偏差：

| 情况 | 例子 | 理由 |
| --- | --- | --- |
| 0 | `Margin="0"`、`BorderThickness="0"` | 清零无样式含义 |
| 1 DIP 发丝线 | `BorderThickness="1"`、分隔线 `Height="1"`、`Thickness(1)` | 物理像素级描边/分隔/微调，不参与间距阶梯 |
| 负数 | `Margin="0,-1,0,0"` | 光学对齐补偿 |
| `Auto` / `*` / `NaN` | Grid 行列 | 布局语义，不是尺寸 |

## 5. 检查器与门禁

```powershell
pwsh -File tools\Test-LpDesignTokens.ps1                  # 日常/构建：只报新增偏差
pwsh -File tools\Test-LpDesignTokens.ps1 -LpReport out.md # 附带 Markdown 报告
pwsh -File tools\Test-LpDesignTokens.ps1 -LpUpdateBaseline # 存量变化后更新基线（保留已有理由）
pwsh -File tools\Test-LpDesignTokens.ps1 -LpStrict        # 清零阶段：任何偏差都失败
```

- 级别：`warn` = 值在阶梯内但内联（待 token 化）；`error` = 值不在阶梯内，或颜色字面量；
- 基线按「文件 + 属性 + 值」冻结次数，同一组合新增出现即失败；
- 已接入 `tools/Build-Lp.ps1`（构建即检查），并列入 [发布检查清单](发布检查清单.md) 的 tag 前必过项。

## 6. 例外与存量处置

首轮扫描（2026-11-15，1.1.3）共 1153 处、368 组：

| 处置 | 组数 | 处数 | 说明 |
| --- | --- | --- | --- |
| 已直接改 | 12 个共享样式 | 27 | 设置/主窗口/更新窗口/Themes 的共享样式改为令牌引用（值不变，零视觉差异） |
| 直接改（下一轮，纯替换） | 203 | 726 | 值已在阶梯内，仅未引用令牌；逐文件替换即可，不需要重拍截图 |
| 需整改（改数值） | 113 | 277 | 间距 141、圆角 45、字号 18、颜色 73；归并到阶梯后需截图核对 |
| 例外冻结 | 52 | 150 | 结构尺寸（`Size` 类 111 处）+ 主题默认色（39 处），理由见下 |

例外分类（基线 `reason` 字段）：

1. **结构尺寸**（`Size` 类，51 组 111 处）：侧栏/列宽（如 198、440）、图标与状态点（14/15/22）、窗口最小尺寸，以及 `LpSwitch`/`LpSlider` 等自定义控件内部的轨道/滑块几何。它们不是控件高度或排版间距，不属于 `LpSpace*`/`LpSize*` 阶梯；新增控件高度仍必须走令牌。
2. **主题默认色**（`ThemeService.cs`，1 组 39 处）：浅/深色画刷的初始值，运行期会被配色方案覆盖；后续应改为从 `Themes.xaml` 读取，属重构项，不在本轮改。

其余颜色字面量（47 组 73 处）仍归「需整改」，不享受例外。

全量明细见 [界面Token扫描结果](界面Token扫描结果.md)。

## 7. 迭代规则

1. 新增界面/控件先查本文档，没有合适的令牌就先在本文件 §2 增补（值是现有界面的归纳，不是新发明），再同步 `DesignTokens.xaml`；
2. 每次改完界面跑一次检查；基线只允许因「修复偏差」而更新，不允许为了放行新增值而更新；
3. 发版前必须检查通过（构建已内置）；`-LpStrict` 清零计划在后续轮次推进。
