# Findio 1.2.0 发布说明

**状态：已发布。** `yunyu697/findio` 已由旧仓库名改到位（旧地址 301）、`main` 已推送、`v1.2.0` tag 已触发 CI
并成功，Release 已上传 4 个资产并通过验签；run 号、资产 size/SHA256 与清单实测见
[1.2.0 发布状态](1.2.0-发布状态.md)。

发布日期：2026-11-15（`publishedAt 2026-11-15T10:42:03Z`）
版本：`1.2.0`（上一正式版 `1.1.3`）
tag：`v1.2.0`（已创建，指向 `872a458`）

版本号按 [版本号规则](版本号规则.md) 进位：改名属于交付形态变化，按 minor 进位，`1.1.3` → `1.2.0`。

## 1. 改名：产品名统一为 Findio，中文名取消

- 产品名、窗口标题、托盘提示、关于页、设置页、README 与全部 docs 统一为 **Findio**；
  中文名删除，不再有「英文名 · 中文名」副标题。
- 程序集与命名空间：`Findio.Shared` / `Findio.Service` / `Findio.UI` / `Findio.ReleaseTool`，解决方案 `Findio.sln`。
- 安装与系统集成：安装包 `Findio-1.2.0-win-x64-setup.exe`、便携包 `Findio-1.2.0-win-x64.zip`；
  安装目录 `%LOCALAPPDATA%\Programs\Findio`（所有用户模式 `Program Files\Findio`）；
  注册表 `HKCU/HKLM\Software\Findio`；计划任务 `Findio-Elevated-<SID>`；
  用户数据根 `%LOCALAPPDATA%\Findio`；环境变量 `FINDIO_DATA_ROOT` / `FINDIO_UPDATE_MIRROR`。
- 更新源：`https://github.com/yunyu697/findio/releases/latest/download/latest.json`。
- 安装器 `AppId` 换为新 GUID，**与旧版卸载项互不覆盖**；本机旧版需用旧卸载器单独卸载（见 §5）。

> **与同名手机定位 App 无关。** Google Play 上另有一款名为 Findio 的 Android 手机 GPS 定位应用
> （开发者 Fortunex Limited），与本产品无任何关联。本产品是 Windows 桌面文件定位工具。
> 命名依据、域名与商店查重结果见 [改名决策](改名决策-Findio.md) 与 [改名查重](改名查重-Findio.md)。

保留不动：图标资源内容、签名私钥与客户端内置公钥、快捷键、配置 JSON 字段。

## 2. 索引扩展名与首次重建

索引文件扩展名由旧扩展名改为 `.fidx`（主索引 `C.fidx`，附加索引 `extras.fidx`），与新名一致。
旧扩展名文件不再读取；**升级或首次启动后会重建一次索引**，重建完成前结果可能为空。
索引目录仍为 `%LOCALAPPDATA%\Findio\service\index`，格式版本未变。

## 5. 本机旧安装清理清单（不进代码，无迁移逻辑）

用旧版自带卸载器 `unins000.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART` 卸载后，逐项核对：

| 位置 | 处理 |
| --- | --- |
| `%LOCALAPPDATA%\Programs\‹旧产品名›`（程序文件） | 卸载器删除，复查不存在 |
| 卸载注册项 `HKCU\...\Uninstall\{3F2B8C71-…}_is1` | 卸载器删除，复查不存在 |
| 开始菜单 `…\Programs\‹旧产品名›` | 卸载器删除，复查不存在 |
| 桌面快捷方式 | 无 |
| 注册表 `HKCU\Software\‹旧产品名›` | 不存在 |
| 计划任务 `‹旧产品名›-Elevated-*` | 不存在 |
| `%LOCALAPPDATA%\‹旧产品名›`（配置、日志、perf、索引、更新包） | 卸载器默认保留；手动整目录删除 |

## 6. 仓库侧动作（已执行）

1. GitHub 仓库已由旧名改为 `findio`（旧地址 301 到新地址），远程地址已同步；已发 tag 不改写。

3. 旧版用户先卸载旧安装，再安装 1.2.0；数据目录不同名，旧数据不会被读取。

## 7. 已知限制

- 旧扩展名索引不兼容，升级后需等待一次重建；
- 新旧安装器 AppId 不同，不能原地覆盖升级，必须先卸载旧版；
- 升级到 1.2.0 后更新源为 `yunyu697/findio`，1.1.3 及更早版本仍指向旧仓库地址（靠 GitHub 的 301 跳转继续可用）。
