# Pathleap 发布检查清单

每次发版（tag `v<版本>`）按顺序核对；任一项不通过则不发版。涉及前台的测量必须单独申请时段，
默认全部走后台/离屏口径。

## 1. 版本与产物

- [ ] `Directory.Build.props` 的 `PathleapVersion` 与 tag 去掉 `v` 后完全一致。
- [ ] 版本格式合法：`<major>.<minor>.<patch>[-alpha<N>]`，`minor` / `patch` ≤ 10。
- [ ] **截图版本一致（必过）**：`pwsh -File tools\Test-LpShotVersions.ps1` 退出码 0；
      当前发布说明引用的截图必须登记在 `docs/shots/manifest.json`，且台账版本等于当前 `PathleapVersion`。
      关于页/设置页这类会显示版本号的截图，升版本后必须重拍，不得沿用上一版画面。
- [ ] **打 tag 前校验（必过）**：`pwsh -File tools\Test-LpTagReady.ps1 -LpPhase pre -LpTag v<版本>` 退出码 0——
      tag 名与 `PathleapVersion` 一致、工作区干净、`HEAD == origin/main`、本地与远端都还没有该 tag。
      1.1.3 曾出现 tag 打在前一提交、CI 误触发后取消的事故，这一步就是防它。
- [ ] **打 tag 后回读（必过）**：推送 tag 后跑 `pwsh -File tools\Test-LpTagReady.ps1 -LpPhase post -LpTag v<版本>` 退出码 0——
      本地与远端 tag 解引用后都必须等于当前 `HEAD`；不一致时先删本地/远端 tag 再重来，不将错就错。
- [ ] Release 构建成功；`Pathleap.UI.exe` / `Pathleap.Service.exe` 的 `ProductVersion` 等于版本号。
- [ ] `dist\Pathleap-<版本>-win-x64.zip` 存在，且包含 `runtimes\win-x64\native\Microsoft.WindowsAppRuntime.Bootstrap.dll`。
- [ ] `dist\Pathleap-<版本>-win-x64-setup.exe` 存在，文件名带版本号。
- [ ] 安装包静默安装/卸载冒烟通过：安装目录与卸载项可创建，卸载后程序文件与快捷方式清除。
- [ ] tag 触发 CI 完成全链路：版本校验 → 变量命名检查 → `selftest` → Release 编译 → 打包 → 创建/更新 Release
      并上传 zip、安装包；配置 `PATHLEAP_SIGNING_KEY` 时同时上传 `latest.json` 与 `latest.json.sig`。
- [ ] zip 必须包含 `runtimes\win-x64\native\Microsoft.WindowsAppRuntime.Bootstrap.dll`（workflow 已硬校验，仍人工抽查一次）。
- [ ] 本机 `Package-Lp*.ps1` 备用路径可用，产物名带版本号。
- [ ] `gh release view <tag> --json assets` 的资产名、大小与本地实测一致；`latest.json` 可从
      `https://github.com/<owner>/<repo>/releases/latest/download/latest.json` 直接取到并通过验签。
- [ ] `dotnet run --project src/Pathleap.ReleaseTool -- selftest` 全通过。
- [ ] `dotnet run --project src/Pathleap.ReleaseTool -- verify --manifest dist/latest.json` 验签通过；
      清单里的 SHA256 与 `Get-FileHash` 结果一致。
- [ ] 本次发版**未生成新密钥**（未运行 `gen-key`）；签名 seed 公钥与客户端内置
      `ReleaseSigning.PublicKeyBase64` 一致（`create` 会硬校验，不一致直接失败、不出清单）。
- [ ] 发布私钥固定不变；如需换钥，已**先**发布内置新公钥的客户端版本，顺序未颠倒。
- [ ] 首个内置签名公钥的版本，发布说明写明「旧版本用户需手动升级」。

## 2. 测试

- [ ] `tools\Test-LpSmoke.ps1 -LpConfiguration Release` 全通过（后台）。
- [ ] `tools\Test-LpUiResults.ps1 -LpConfiguration Release` 全通过（后台，`QUERY`/`NAV`）。
- [ ] 查询性能用 Release 构建复测，P95 ≤ 30 ms；Debug 数据不作为结论。
- [ ] 测试过程未反复抢前台、未向用户活动窗口注入键鼠。
- [ ] 若跑前台唤醒基准：已提前告知时段与预计时长，每轮只集中跑一次，跑完立即让出。
- [ ] **界面改动附真实截图与设计稿并排对照**（`docs/界面对照.html`），逐项列出「设计稿要求 / 当前实现 / 差距 / 是否解决」；截图通道、缩放比例、会话状态已注明。
- [ ] 界面中未接通的控件已在界面上标注「未接入」，并在 `docs/功能状态清单.md` 中有对应「未实现」行（README 只做摘要，不作为台账）。
- [ ] **启动可见性（必过）**：`pwsh -File tools\Test-LpLaunchWindows.ps1` 退出码 0（先开启「始终以管理员身份运行」，跑完恢复关闭）。
      口径：真实入口（桌面快捷方式 → explorer 打开）下，启动前开始真实枚举顶层窗口（`EnumWindows` + `IsWindowVisible` + DWM cloaked + 扩展边框，≥200 轮/秒）；
      中转实例顶层窗口 0 个；**启动链内**无控制台窗口变为可见（按窗口 owner 的祖先进程链判定，外部程序的控制台窗口单列、不计入；无法归属的按失败处理）；
      提权实例只有主窗口 1 扇已绘制窗口（可见、未被 DWM 遮蔽、非零尺寸），首次绘制后无隐藏/被遮蔽回退、几何不变；
      回退若发生在「前台已被其它进程拿走」时，按「失焦即隐藏」的既有设计记为外部干扰并列出，读不到前台或前台仍在本进程/启动链内仍判失败。
      几何一律记 `DWMWA_EXTENDED_FRAME_BOUNDS` 物理像素并附 DPI 与 DIP，不与 `GetWindowRect` 或历史数字直接比。
      与历史几何数字不一致时，必须附本轮原始读数：`GetMonitorInfoW` 的 `rcMonitor` / `rcWork` 四边坐标（物理像素）、`GetDpiForMonitor` 的 X/Y 与缩放百分比、`EnumDisplaySettingsW` 当前模式，以及窗宽计算式与取整方式；
      **不得用窗口宽度反推工作区**（例如「1470×2=2940」），否则视为循环论证，结论不成立。
      不允许以「代码里有 `CREATE_NO_WINDOW`」代替本项。该脚本会短暂显示主窗口约 6 秒，不注入键鼠、不抢前台。
- [ ] **界面令牌检查通过（必过）**：`pwsh -File tools\Test-LpDesignTokens.ps1` 退出码 0（`Build-Lp.ps1` 已内置，tag 构建会跑）；
      本版新增偏差已修复，或按 `docs/界面设计规范.md` §6 登记了理由；不得为放行新增硬编码而更新基线。
- [ ] 无法实测的界面项标注「未验证」或「被环境挡住」，不写成已完成。

## 3. 文档与合规

- [ ] README 已同步（**必过**）：版本号、已实现/未完成能力、性能实测数据及口径、安装/构建方式、已知限制。
- [ ] **功能状态清单已复核（必过）**：`docs/功能状态清单.md` 的每一行状态与证据都是本次发版时点的真实状态；
      本版新增或改动的设置页条目都能在 §1 找到对应行；本版涉及的状态变化（新实现 / 新降级 / 新验证）已更新；
      并在文件末尾「更新记录」登记版本号、日期、复核人。
      **谁在什么时点**：复核人与登记人 = 本版发版负责人（创建 tag 的人），时点 = **创建 tag 之前**；
      CI 通过后由同一人回填 CI 运行号与 Release 资产链接。未登记即视为发布流程未完成，不发版。
- [ ] README 中每个性能数字都能指向 `docs/` 下的实测报告章节。
- [ ] 新增/变更的发布说明已落盘，并写明未完成验证项，不把待验证写成已达成。
- [ ] 禁用词扫描为空：`git grep -in 'l[i]stary'`、`git log --all -i --grep='l[i]stary'`、
      以及排除 `.git/bin/obj/dist` 的全仓库内容扫描。
- [ ] 若历史提交含禁用词：不回写历史，在发布说明中披露并附检索证据。
- [ ] 版本号规则、发布说明与 README 中的产物名一致。

## 4. 收尾

- [ ] 停止所有测试用 `Pathleap.UI.exe` / `Pathleap.Service.exe` 进程。
- [ ] 跑过提权/启动可见性测试的机器已复原：桌面无 `Pathleap-提权入口测试.lnk`、计划任务 `Pathleap-Elevated-<SID>` 已删除、
      `config.json` 的 `alwaysRunAsAdmin=false` 且无 `indexDirectories` / `networkLocations` 测试残留、无 `pending-launch.txt`。
- [ ] 工作区干净（`git status --short` 无预期外文件）。
- [ ] CI 运行链接与实际结果已回报（tag 完整链路；缺 `PATHLEAP_SIGNING_KEY` 时如实记录「本次未生成清单」）。
