## 6. 验签（ReleaseTool verify）

1. CI 内：tag run `43705189156` 在「发布 GitHub Release（仅 tag）」一步执行
   `ReleaseTool create`（seed 签名）→ `ReleaseTool verify --manifest dist/latest.json` → 通过后才上传清单。
2. 本地复核：下载 Release 上的 `latest.json` 与 `latest.json.sig` 后执行

   ```
   dotnet run --project src/Findio.ReleaseTool -- verify --manifest <下载目录>/latest.json
   ```

   输出「验签通过: …（version=1.2.0）」，退出码 0，即签名私钥（Secret 内容）与客户端内置公钥匹配。
