## 2. 卡在哪（按依赖顺序）

1. **GitHub 仓库名仍是旧名**：客户端 `ReleaseFeed.RepoName` 已是 `findio`，但远端仓库没有改名，
   现在推 tag 会得到一个资产 URL 指向 `yunyu697/findio` 的 Release，清单里的下载地址与客户端实际仓库不一致。
2. **签名 Secret 名未改**：`.github/workflows/build.yml` 读 `secrets.FINDIO_SIGNING_KEY`，仓库里只有
   旧名 Secret（`<旧产品名大写>_SIGNING_KEY`）。直接推 tag 会在「生成清单」一步命中
   `未配置 FINDIO_SIGNING_KEY` 分支：
   zip / setup 照常上传，但 `latest.json`、`latest.json.sig` 不生成，更新链路仍然断。
3. **本地 33 个提交未推送**：改名与方向 B 全部只在本地 `main`。
4. 上述三项都在仓库外（GitHub 设置与 git push），不在代码里，也没有写自动迁移。
